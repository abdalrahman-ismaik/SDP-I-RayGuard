## GitHub record expected by the course

The announcement calls for the code, meaningful development history and project documentation in the group GitHub record, including proposal, progress documents, requirements/specifications, designs/sketches, implementation decisions, project plan/Gantt chart, meeting minutes with teammates and supervisors, decisions, code and final report. Each student must be able to show their own work and explain how it affected the shared group result.

The handbook additionally says implementation details, design, meeting minutes, requirements, specifications and AI prompts should be reported on GitHub and in the final report. Apply project privacy rules: do not commit private source PDFs, credentials, weights, scans, personal/session records or machine-specific paths. Summarize relevant evidence and reference approved artifacts instead.

## Individual evidence and assessment

Each student should arrange a supervisor review of their GitHub contribution record as soon as possible, normally before the final presentation or immediately after it. The announcement associates this individual demonstration with **15%**. Bring concrete links to authored/reviewed commits, issues or task records, documents and decisions, and explain the work and its effect. A username or commit count alone does not explain contribution.

The supplied August 2026 handbook's SDPI detailed rubric allocates individual marks as follows:

| Assessment area | Weight | Rubric focus |
|---|---:|---|
| GitHub record | 15% | Development history, version control, identifiable contributions, setup/documentation and repository organization |
| Final report | 20% | Problem/objectives, method/design, development, results/evaluation, conclusions/limitations, writing/references |
| Final presentation | 20% | Structure, technical explanation, visuals, delivery and timing |
| Final live demo | 25% | Core functions, end-to-end integration, output/performance, reliability/error handling and demo execution |
| Q&A | 20% | Technical understanding, justification, critical evaluation, individual contribution, clarity/independence |

These are the **supervisor form's** weights, totaling 100 within that form. The SDP I
**examiner form** instead assigns report 20, presentation 20, live demo 25 and Q&A 35,
with no separate GitHub category. Handbook §6 gives supervisor and examiner 50% each;
the table above is not the combined course weighting. Both detailed rubrics and their
evidence mapping are recorded in the [report specification](final-report-requirements.md#assessment-coverage).
The announcement's 15% wording remains recorded separately; clarify any intended
course-wide interpretation rather than silently equating it with the combined grade.
